# GAMI BOYZ

Static brand site for the Gami Boyz brotherhood lane inside the Kurogami universe.

## Run locally

Open `index.html` directly, or serve the folder with:

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Routes are hash-based for static hosting: `/`, `/club`, `/access`, `/gallery`, `/token`, `/join`, and `/members`.
