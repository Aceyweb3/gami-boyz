# GAMI BOYZ

Static brand site for the Gami Boyz brotherhood lane inside the Kurogami universe.

## Run locally

Open `index.html` directly, or serve the folder with:

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Routes are hash-based for static hosting. The top navigation links to `/agentic`, `/opportunity`, `/desks`, `/brief`, `/kage`, `/network`, `/media`, `/manga`, and `/join`; the home-page sections also include the room, creator path, and sponsor request. Brief issue `/brief/001` opens as a standalone read. Existing routes include `/club`, `/access`, `/gallery`, `/token`, `/onboarding`, `/terms`, and `/members`.
